## 案例索引

### 门铃用旧 m4.yml 误判测试号密码没配（2026-08）

**案例类型**: 误判根因  
**核心问题**: PMS 测号登不上被说成 M4 没配密钥；实际是门铃读了 fetch 前的旧 yaml  
**相关文档**: [摘要](./m4-doorbell-stale-m4-yml-2026-08.md)（全文在 global-governance）

### Next-AI-Draw-IO Web部署失败

**案例类型**: 技术选型错误、架构设计偏差
**严重程度**: 🔴 高
**案例价值**: ⭐⭐⭐⭐⭐ 高价值

**核心问题**:
- 自托管Draw.io引入不必要的复杂性
- 配置持久化问题（localStorage不适合长期使用）
- 维护成本远超预期

**关键教训**:
- 需求分析要深入
- 技术选型要有依据
- 成本评估要全面

### 招聘人格评测 assessment 搬迁与 PM2 部署（2026-04）

**案例类型**: 运维配置错误、部署与 API 契约不一致  
**严重程度**: 🟡 中（公网不可用 / 数据展示异常，可修复）  
**案例价值**: ⭐⭐⭐⭐ 高（Cloudflare Tunnel + Next standalone + SQLite 典型组合）

**核心问题**:
- Tunnel 上游写死旧内网 IP 与错误端口导致 502
- standalone 未同步静态资源导致 404
- `next build` 覆盖 standalone 内数据库
- API 返回 snake_case 导致前端列表候选人空白

**相关文档**:
- [复盘全文（单一维护）](./personality-assessment-deployment-2026-04.md)

### HR 招聘助手 PyMySQL 未 commit（2026-05）

**案例类型**: 数据库事务、部署验收疏漏  
**严重程度**: 🟡 中（登录 403，修复后正常）  
**案例价值**: ⭐⭐⭐⭐ 高（脚本 `[ok]` 与库中 0 行矛盾，PyMySQL 通用）

**核心问题**:
- `create_user()` INSERT 后未 `conn.commit()`，连接关闭事务回滚
- 同连接内 SELECT 可见行，脚本误报成功
- 排查链长，先后怀疑 JSAPI、钉钉权限、PM2 未读 `.env`

**相关文档**:
- [复盘全文（单一维护）](./hr-recruitment-pymysql-commit-2026-05.md)

## 案例分类

### 按类型分类

- **技术选型错误**: 选择了不适合的技术方案
- **架构设计偏差**: 架构设计不合理
- **需求分析不足**: 需求分析不深入
- **成本评估偏差**: 成本评估不全面

### 按严重程度分类

- **🔴 高**: 导致项目方向调整或失败
- **🟡 中**: 导致项目延期或成本超支
- **🟢 低**: 导致小问题或技术债务

## 案例使用指南

### 项目启动前

1. 阅读相关失败案例
2. 使用案例中的检查清单
3. 避免案例中的错误

### 项目进行中

1. 定期回顾失败案例
2. 识别潜在问题
3. 及时调整方案

### 项目结束后

1. 分析项目中的问题
2. 提炼经验教训
3. 入库失败案例
