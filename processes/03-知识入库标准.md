# 知识入库标准

**用途**: 规范知识入库流程和标准
**使用时机**: 知识提炼后
**更新日期**: 2026年1月

---

## 📋 入库标准

### 1. 失败案例入库标准

#### 必需文档

- [ ] **案例摘要**（1页纸）
  - 问题描述
  - 根本原因
  - 关键教训
  - 预防措施

- [ ] **详细分析**
  - 项目背景
  - 失败过程时间线
  - 根本原因分析
  - 影响分析

- [ ] **决策复盘**
  - 关键决策复盘
  - 决策成功率分析

- [ ] **技术债务清单**
  - 技术债务分类
  - 技术债务统计

- [ ] **预防措施**
  - 需求分析预防措施
  - 技术选型预防措施

---

#### 目录结构

```
failure-cases/
└── [项目名]/
    ├── 01-案例摘要.md
    ├── 02-详细分析.md
    ├── 03-决策复盘.md
    ├── 04-技术债务清单.md
    └── 05-预防措施.md
```

---

#### 命名规范

- **项目名**: 使用项目实际名称（小写，连字符分隔）
- **文件名**: 使用序号+描述（如：01-案例摘要.md）

---

### 2. 反模式卡片入库标准

#### 必需内容

- [ ] **模式名称**: 清晰简洁
- [ ] **模式定义**: 明确定义
- [ ] **识别特征**: 可识别的特征
- [ ] **危害分析**: 危害和影响
- [ ] **案例**: 相关案例
- [ ] **预防措施**: 预防方法

---

#### 文件位置

```
patterns/anti-patterns/
└── [模式名称].md
```

---

#### 命名规范

- **文件名**: 使用模式名称（中文，清晰描述）

---

### 3. 决策框架入库标准

#### 必需内容

- [ ] **框架说明**: 框架用途和使用时机
- [ ] **使用指南**: 如何使用框架
- [ ] **检查清单/评估表**: 可操作的清单或表格
- [ ] **使用示例**: 实际使用示例

---

#### 文件位置

```
decision-frameworks/
└── [框架名称].md
```

---

#### 命名规范

- **文件名**: 使用框架名称（中文，清晰描述）

---

## 📝 入库流程

### 步骤1: 准备入库

- [ ] 知识提炼完成
- [ ] 文档完整
- [ ] 符合入库标准

---

### 步骤2: 创建目录结构

```bash
# 失败案例
mkdir -p 03-knowledge-base/failure-cases/[项目名]

# 反模式卡片
# 文件直接放在 patterns/anti-patterns/

# 决策框架
# 文件直接放在 decision-frameworks/
```

---

### 步骤3: 复制文档

```bash
# 复制案例文档
cp -r [项目文档] 03-knowledge-base/failure-cases/[项目名]/

# 复制反模式卡片
cp [反模式文档] 03-knowledge-base/patterns/anti-patterns/

# 复制决策框架
cp [框架文档] 03-knowledge-base/decision-frameworks/
```

---

### 步骤4: 更新索引

- [ ] 更新失败案例库索引
- [ ] 更新反模式库索引
- [ ] 更新决策框架索引
- [ ] 更新知识库导航

---

### 步骤5: 验证入库

- [ ] 文件位置正确
- [ ] 文档完整
- [ ] 索引更新
- [ ] 链接有效

---
