# 项目复盘流程

**用途**: 系统化进行项目复盘，提炼经验教训
**使用时机**: 项目结束后
**更新日期**: 2026年1月

---

## 📋 复盘流程

### 阶段1: 准备阶段（1-2小时）

#### 1.1 收集资料

**收集内容**:
- [ ] 项目文档（需求、设计、计划）
- [ ] 代码仓库（Git提交记录）
- [ ] 问题记录（Issue、Bug报告）
- [ ] 会议记录（决策记录）
- [ ] 测试报告（功能测试、性能测试）

**收集方法**:
```bash
# 收集项目文档
find project-dir -name "*.md" -type f

# 收集Git提交记录
cd project-dir && git log --oneline > git-log.txt

# 收集问题记录
find project-dir -name "*issue*" -o -name "*bug*"
```

---

#### 1.2 准备复盘模板

**使用模板**:
- [项目复盘模板](../../02-templates/post-mortem/复盘报告模板.md)
- [经验教训模板](../../02-templates/post-mortem/经验教训模板.md)

---

### 阶段2: 复盘会议（2-4小时）

#### 2.1 项目回顾

**回顾内容**:
- [ ] 项目目标是否达成？
- [ ] 项目时间是否按计划？
- [ ] 项目成本是否在预算内？
- [ ] 项目质量是否满足要求？

**回顾方法**:
- 使用项目复盘模板
- 对比计划和实际
- 记录差异和原因

---

#### 2.2 问题分析

**分析内容**:
- [ ] 遇到了哪些问题？
- [ ] 问题的根本原因是什么？
- [ ] 如何解决的？
- [ ] 是否可以预防？

**分析方法**:
- 使用5 Why分析法
- 使用根本原因分析流程
- 记录解决方案

---

#### 2.3 经验总结

**总结内容**:
- [ ] 哪些做得好？为什么？
- [ ] 哪些做得不好？为什么？
- [ ] 有哪些经验教训？
- [ ] 有哪些最佳实践？

**总结方法**:
- 使用经验教训模板
- 提炼可复用的模式
- 记录最佳实践

---

### 阶段3: 知识提炼（2-3小时）

#### 3.1 提炼失败案例（如果项目失败）

**提炼内容**:
- [ ] 案例摘要（1页纸）
- [ ] 详细分析
- [ ] 决策复盘
- [ ] 技术债务清单
- [ ] 预防措施

**提炼方法**:
- 使用失败案例模板
- 参考[知识提炼指南](./02-知识提炼指南.md)
- 参考[知识入库标准](./03-知识入库标准.md)

---

#### 3.2 提炼成功案例（如果项目成功）

**提炼内容**:
- [ ] 案例摘要
- [ ] 成功因素分析
- [ ] 最佳实践提炼
- [ ] 可复用模式

**提炼方法**:
- 使用成功案例模板
- 提炼最佳实践
- 创建正模式卡片

---

#### 3.3 提炼反模式（如果发现问题）

**提炼内容**:
- [ ] 模式名称
- [ ] 识别特征
- [ ] 危害分析
- [ ] 预防措施
- [ ] 相关案例

**提炼方法**:
- 参考现有反模式卡片
- 创建新的反模式卡片
- 关联到失败案例

---

### 阶段4: 知识入库（1小时）

#### 4.1 入库失败案例

**入库位置**: `03-knowledge-base/failure-cases/[项目名]/`

**入库内容**:
- 案例摘要
- 详细分析
- 决策复盘
- 技术债务清单
- 预防措施

**入库方法**:
- 参考[知识入库标准](./03-知识入库标准.md)
- 创建案例目录
- 复制案例文档

---

#### 4.2 入库成功案例

**入库位置**: `03-knowledge-base/success-cases/[项目名]/`

**入库内容**:
- 案例摘要
- 成功因素分析
- 最佳实践
- 可复用模式

---

#### 4.3 更新索引

**更新内容**:
- [ ] 更新失败案例库索引
- [ ] 更新成功案例库索引
- [ ] 更新模式库索引
- [ ] 更新知识库导航

---

## 📝 复盘检查清单

- [ ] 项目回顾完成

### 复盘后检查

- [ ] 复盘报告完成
- [ ] 经验教训提炼完成
- [ ] 知识入库完成
- [ ] 索引更新完成
