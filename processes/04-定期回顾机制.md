# 定期回顾机制

**用途**: 建立持续的知识库维护和更新机制
**使用时机**: 定期执行
**更新日期**: 2026年1月

---

## 📅 回顾频率

### 每月回顾（每月1日）

**回顾内容**:
- [ ] 知识库健康检查
- [ ] 新知识入库
- [ ] 索引更新
- [ ] 链接验证

**执行时间**: 1-2小时

---

### 每季度回顾（每季度第1个月1日）

**回顾内容**:
- [ ] 最佳实践更新
- [ ] 模式库更新
- [ ] 决策框架优化
- [ ] 知识库结构优化

**执行时间**: 2-4小时

---

### 年度回顾（每年1月1日）

**回顾内容**:
- [ ] 知识库全面审查
- [ ] 过时知识清理
- [ ] 知识库结构优化
- [ ] 知识沉淀机制优化

**执行时间**: 4-8小时

---

## 📋 每月回顾检查清单

### 1. 知识库健康检查

- [ ] **文档完整性**
  - 检查所有案例文档是否完整
  - 检查所有模式卡片是否完整
  - 检查所有决策框架是否完整

- [ ] **链接有效性**
  - 检查内部链接是否有效
  - 检查外部链接是否有效
  - 修复失效链接

- [ ] **索引准确性**
  - 检查索引是否准确
  - 检查索引是否完整
  - 更新索引

---

### 2. 新知识入库

- [ ] **检查新项目**
  - 是否有新项目需要复盘？
  - 是否有新知识需要入库？

- [ ] **入库新知识**
  - 提炼新知识
  - 入库新知识
  - 更新索引

---

### 3. 知识库统计

**统计内容**:
- 案例数量
- 模式数量
- 框架数量
- 文档总数

**统计方法**:
```bash
# 统计案例数量
find 03-knowledge-base/failure-cases -mindepth 1 -maxdepth 1 -type d | wc -l

# 统计模式数量
find 03-knowledge-base/patterns/anti-patterns -name "*.md" | wc -l

# 统计框架数量
find 03-knowledge-base/decision-frameworks -name "*.md" | wc -l
```

---

## 📋 每季度回顾检查清单

### 1. 最佳实践更新

- [ ] **回顾成功案例**
  - 分析成功因素
  - 提炼最佳实践
  - 更新最佳实践库

- [ ] **更新模式库**
  - 创建新的正模式卡片
  - 更新现有模式卡片
  - 删除过时模式

---

### 2. 决策框架优化

- [ ] **回顾决策框架使用情况**
  - 哪些框架使用频率高？
  - 哪些框架需要优化？

- [ ] **优化决策框架**
  - 更新检查清单
  - 优化评估表
  - 添加使用示例

---

### 3. 知识库结构优化

- [ ] **评估知识库结构**
  - 结构是否合理？
  - 是否需要调整？

- [ ] **优化知识库结构**
  - 调整目录结构
  - 优化分类方式
  - 更新导航文档

---

## 📋 年度回顾检查清单

### 1. 知识库全面审查

- [ ] **审查所有案例**
  - 案例是否仍有价值？
  - 案例是否需要更新？

- [ ] **审查所有模式**
  - 模式是否仍然适用？
  - 模式是否需要更新？

- [ ] **审查所有框架**
  - 框架是否仍然有效？
  - 框架是否需要优化？

---

### 2. 过时知识清理

- [ ] **识别过时知识**
  - 技术已过时
  - 方法已改进
  - 不再适用

- [ ] **清理过时知识**
  - 归档过时知识
  - 删除无效知识
  - 更新索引

---

### 3. 知识沉淀机制优化

- [ ] **评估知识沉淀机制**
  - 机制是否有效？
  - 流程是否需要优化？

- [ ] **优化知识沉淀机制**
  - 优化流程
  - 更新模板
  - 改进工具
