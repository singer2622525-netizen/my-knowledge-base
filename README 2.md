## 📖 使用指南

### 项目启动前

1. **阅读失败案例**: 了解类似项目的失败原因
   - 查看 `failure-cases/` 目录
   - 重点关注需求分析、技术选型、成本评估

2. **阅读反模式**: 识别和避免反模式
   - 查看 `patterns/anti-patterns/` 目录
   - 重点关注与项目相关的反模式

3. **使用检查清单**: 使用决策框架
   - 使用 `decision-frameworks/项目启动检查清单.md`
   - 使用 `decision-frameworks/技术选型评估表.md`

---

### 项目进行中

1. **定期回顾**: 定期回顾失败案例和反模式
   - 每月回顾一次
   - 识别潜在问题

2. **使用决策框架**: 使用决策框架指导决策
   - 技术选型时使用评估表
   - 风险评估时使用矩阵

---

### 项目结束后

1. **项目复盘**: 进行项目复盘
   - 使用复盘模板
   - 分析成功/失败因素

2. **提炼知识**: 提炼经验教训
   - 成功项目 → `success-cases/`
   - 失败项目 → `failure-cases/`

3. **更新知识库**: 更新知识库
   - 提炼新的反模式
   - 更新决策框架
   - 更新最佳实践
