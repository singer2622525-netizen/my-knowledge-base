# 项目启动检查清单

**用途**: 项目启动前的系统性检查，确保项目有充分的准备和依据
**使用时机**: 项目启动前
**更新日期**: 2026年1月

---

## 1. 需求分析检查

### 1.1 需求澄清

- [ ] **需求是否明确？**
  - 需求描述是否清晰？
  - 需求是否有歧义？
  - 需求是否可测量？

- [ ] **需求是否合理？**
  - 需求是否技术上可行？
  - 需求是否经济上可行？
  - 需求是否符合业务目标？

- [ ] **需求是否完整？**
  - 是否考虑了所有使用场景？
  - 是否考虑了边界情况？
  - 是否考虑了异常情况？

- [ ] **需求优先级是否明确？**
  - P0功能（必须）
  - P1功能（重要）
  - P2功能（可选）

- [ ] **是否有替代方案？**
  - 是否有其他方案可以满足需求？
  - 替代方案的优劣是什么？

---

### 1.2 使用场景分析

- [ ] **使用频率**
  - 使用频率如何？（每天/每周/每月）
  - 使用时长如何？（长期/短期/临时）

- [ ] **用户类型**
  - 用户类型是什么？（个人/团队/企业）
  - 用户规模如何？

- [ ] **使用环境**
  - 使用环境是什么？（在线/离线/混合）
  - 网络环境如何？

- [ ] **配置需求**
  - 配置持久化需求是什么？
  - 配置安全性要求是什么？

---

## 使用说明

### 使用方法

1. **项目启动前**: 使用此清单进行系统性检查
2. **逐项检查**: 逐项检查每个检查项
3. **记录结果**: 记录检查结果和发现的问题
4. **解决问题**: 解决发现的问题
5. **确认完成**: 确认所有检查项都已完成

### 检查频率

- **项目启动前**: 必须完成
- **项目进行中**: 每月回顾
- **项目变更时**: 重新检查
